# 用有限附加状态扩展最短路节点

## 经验结论

当图上的后续转移不仅取决于当前位置，还取决于某个规模有限的附加状态时，可以把原图节点 `u` 扩展为 `(u, s)`，其中 `s` 只保留会影响未来转移的信息。

随后不要因为“状态中出现了数值变化”就直接套 Dijkstra，而应重新判断扩展图中真正的边权。

如果每次原图移动的代价仍然相同，则扩展图仍是单位边权图，可以直接使用 BFS；只有实际优化目标对应的边权不同时，才需要 Dijkstra 等带权最短路算法。

## 适用信号

题目同时出现以下特征时，可以考虑状态扩展：

- 要求最少步数、最短时间或其他路径最优值；
- 能否继续转移、最终是否合法，取决于路径上的某个累计信息；
- 这个累计信息可以压缩成有限数量的等价状态；
- 到达“同一位置 + 同一附加状态”后，此前具体路径不会继续影响未来。

常见附加状态可能包括余数、奇偶性、使用次数、朝向、钥匙状态或某个有限布尔状态。

## 常见 blocker 或失败症状

一种常见卡点是把“状态发生了多少变化”和“这条边的代价是多少”混为一谈。

例如移动到一个新节点后，余数状态可能从 `3` 变成 `8`。这个变化量由题目数据决定，但并不意味着这条边的最短路权值是 `5` 或 `8`。

如果题目优化的是移动次数，并且每次移动都只算一步，那么无论附加状态怎样变化，这条扩展图边的权值仍然是 `1`。

另一种 blocker 是保存了完整累计值，导致状态数过大。此时应先判断两个累计值在什么条件下对未来完全等价，只保存这个等价类。

## 原因与原理

状态扩展的关键不是机械地“多开一维数组”，而是确定未来决策真正依赖哪些信息。

假设两条路径都到达节点 `u`，对应附加信息分别为 `x` 和 `y`。如果 `x` 与 `y` 在题目的所有后续转移和终点判定中表现完全相同，就没有必要区分它们。

例如后续只关心路径累计和模 `k` 的结果，则所有满足

`x mod k = y mod k`

的累计值都属于同一个状态。

因此可以只保存：

`(u, sum mod k)`

而不是保存完整的 `sum`。

扩展完成后，原问题就变成普通图上的最短路问题。此时使用 BFS、0-1 BFS 还是 Dijkstra，由扩展图中的实际边权决定，而不是由附加状态本身的数值决定。

## 验证方式

据 @jianhuowang 自述，在牛客题目“走一个大整数迷宫”中实际使用了这一模型并 AC。

该题中，路径累计值经过同余化简后只需保留模 `p-1` 的余数，因此状态写为：

`(x, y, r)`

其中 `r` 为当前路径累计值模 `p-1` 的结果。

每次在网格中移动一格仍然只增加一步，因此扩展图中的所有边权均为 `1`。使用 BFS 后，某个 `(x, y, r)` 第一次被访问时即取得最小步数。

本条目前只有这一单题案例支持，尚未通过多个不同类型问题验证全部迁移场景。

## 边界与反例

状态扩展不意味着一定使用 BFS。

如果扩展图中不同转移具有不同的实际代价，例如进入不同格子需要支付不同费用，那么即使状态仍写成 `(u, s)`，普通 BFS 的“第一次访问即最优”也不再成立，应根据边权选择 0-1 BFS、Dijkstra 或其他算法。

此外，只有当附加状态规模可控时才能直接展开。如果状态为大集合、完整历史或取值范围极大，还需要进一步压缩，否则时间或空间复杂度可能不可接受。

不能为了减少状态数随意合并状态。只有当两个状态对所有未来转移和最终判定等价时，才能视为同一个状态。

## 核心模型或不变量

将原图节点

`u`

扩展为

`(u, s)`

其中 `s` 是足以决定未来行为的最小有限状态。

对于余数型问题，一个典型模型是：

`dist[u][r]`

表示到达节点 `u` 且当前累计值模 `k` 等于 `r` 时的最优距离。

从 `(u, r)` 经过原图边转移到 `v` 时，根据题意计算新状态 `r'`，于是建立扩展图边：

`(u, r) -> (v, r')`

正确性的关键在于：一旦当前位置和附加状态完全相同，过去路径中已经被状态压缩掉的信息不能再影响未来。

## 复杂度与约束

如果原图有 `V` 个节点、`E` 条边，附加状态共有 `S` 种，则直接状态扩展后通常有：

- 节点数：`O(VS)`
- 边数：`O(ES)`

单位边权 BFS 的时间复杂度通常为 `O(VS + ES)`，空间复杂度为 `O(VS)`。

因此使用该方法前需要确认 `S` 足够小。

例如保存模 `k` 的余数时，一般有 `S = k`。

## 实现风险

第一，visited 或 dist 必须针对完整状态 `(u, s)`，不能只标记原图节点 `u`。

同一个位置可能以不同附加状态多次到达，这些状态的未来行为可能不同。

第二，初始状态要确认起点本身是否参与累计。

第三，不要把“改变状态的数值”误认为最短路边权。应单独回答两个问题：

1. 这次转移后状态 `s` 如何变化？
2. 题目的优化目标因此增加多少代价？

第四，如果使用 BFS，只有在扩展图边权全部相同时，第一次访问状态才可以直接视为最优。

## 迁移识别

以后遇到“最短路 + 路径附加限制”时，可以依次问：

1. 只知道当前位置，是否足以决定下一步是否合法？
2. 如果不够，还需要知道过去路径中的什么信息？
3. 这部分信息能否按照“未来表现相同”压成有限状态？
4. 扩展为 `(位置, 状态)` 后，每条边真正的优化代价是什么？
5. 根据这个边权，再选择 BFS、0-1 BFS 或 Dijkstra。

尤其当题目出现“路径和模某个数”“奇偶性”“最多使用若干次”“是否获得某种能力”等条件时，可以优先尝试这一建模。
