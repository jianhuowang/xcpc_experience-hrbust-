# ABC221 E (LEQ)：贡献法迁移 + 树状数组入门

## 经验结论
求"所有子序列/子集"的贡献和时，先**固定决定贡献的关键位置**，把中间可自由选择的位置压成 2 的幂，即可把指数级枚举降到多项式级。以 ABC221 E 为例：固定 `i < j` 且 `a[i] <= a[j]`，中间 `j-i-1` 个位置每个可"选/不选"，贡献恰为 `2^(j-i-1)`。瓶颈在 O(n^2)；把 `2^(j-i-1)` 拆成 `2^(j-1) * 2^(-i)`，即"固定右端点 j，查询历史上 `a[i] <= a[j]` 的 `2^(-i)` 权值和"，即可用离散化 + 按值前缀和（树状数组）优化到 O(n log n)。

## 适用信号
- 题目要求"所有/任取满足条件的子序列（或子集）的贡献和"，贡献由被选中的位置/元素决定。
- 需要动态统计"历史中满足值约束的元素权值和"，如"查询历史上值 <= 当前值的权值和"。
- 有单点修改 + 前缀/区间查询需求，且值域较大需要离散化。

## 常见 blocker 或失败症状
- 直接枚举所有子序列，`O(2^n)` 或 `O(n^2)` 超时。
- 想动态维护"历史值 <= 当前值的权值和"，但不知道用什么结构。
- **离散化漏掉 `sort(b)`**：`unique` 和 `lower_bound` 都依赖有序数组；漏 `sort` 会导致 `lower_bound` 结果错乱，表现为 WA。
- 树状数组是新前置，初次接触时 `lowbit` / 单点加 / 前缀和概念混淆，实现受挫；`2^(-i)` 取模时需处理逆元。

## 原因与原理
- **子序列计数**：固定一组关键位置后，其余自由位置每个可"选/不选"，因此贡献乘以 `2^(自由位置数)`。
- **拆分贡献**：`2^(j-i-1) = 2^(j-1) * 2^(-i)`，将同时依赖 i、j 的项拆成"只依赖 j"与"只依赖 i"的两个因子，便于用结构性前缀聚合。
- **树状数组**：`lowbit` 定位覆盖区间，单点加与前缀和均为 O(log n)；"按值"组织下标，即可查询值域前缀的和。
- **离散化**：把大值域映射到连续下标；但 `unique` / `lower_bound` 必须在**有序**数组上工作，所以要先 `sort`。

## 验证方式
- 用暴力枚举所有子序列（`O(2^n)`）在小数据上对拍，确认贡献式与最终结果一致。
- 覆盖离散化边界：重复值、最小值、最大值、单元素数组、全相等数组（此时所有 `i<j` 都贡献，`2^(j-i-1)` 求和）。
- 逐步去掉 `sort(b)` 复现 WA，确认根因是离散化依赖有序。

## 边界与反例
- 注意比较方向：`a[i] <= a[j]` 与 `a[i] < a[j]` 计数对象不同，等于号归属要严格按题意。
- `2^(-i)` 若需取模，用逆元（模数为质数时用费马小定理）；若模数非质数需换用其他处理。
- 树状数组查询是前缀和；若需区间 `[l, r]`，要用两次前缀和做差分。
- 贡献法中"固定哪一端"可多种（固定 i 或固定 j），选择决定统计方向与结构。

## 暴露的问题
- 能独立推出 O(n^2) 的贡献式并指出复杂度是瓶颈，但优化所需的"树状数组"是全新前置，是当前主要缺口。
- 在树状数组实现中犯的离散化漏 `sort` 错误，反映出对"结构依赖有序性"的理解不深。

## 训练动作
- 先独立固定 `i<j` 且 `a[i]<=a[j]`，推导出单次贡献 `2^(j-i-1)`，并确认 O(n^2) 为瓶颈。
- 首次系统学习树状数组：`lowbit`、单点加、前缀和、离散化；理解把 `2^(j-i-1)` 拆成左右端点权值、固定右端点再查询历史值约束的方法。
- 在提示下完成实现并 AC；调试中补上离散化遗漏的 `sort` 后通过。

## 完成标准
- 能独立给出 O(n^2) 的贡献式，并说明其复杂度瓶颈。
- 能在参考/提示下正确实现"离散化 + 树状数组"的 O(n log n) 解法并通过题目。
- 能讲清关键一步：固定右端点 j，查询历史 `a[i]<=a[j]` 的 `2^(-i)` 权值和。
