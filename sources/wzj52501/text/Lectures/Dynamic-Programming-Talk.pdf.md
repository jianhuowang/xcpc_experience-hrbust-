合并石子

合并成一堆。规定每次只能选相邻的 2 堆石子合并成新的一堆，并
将新的一堆石子数记为该次合并的代价。计算将 n 堆石子合并成一
堆的最小代价。
n [U+0014] 100; Ai [U+0014] 1000
设 f(i; j) 表示把 [i; j] 区间内所有石子合并成 1 堆的最小代价。

两堆石子。
f(i; j) = min ff(i; k) + f(k + 1; j) + sum(i; j)g (i [U+0014] k < j)
初始 f(i; i) = 0 ，答案即为 f(1; n)。
