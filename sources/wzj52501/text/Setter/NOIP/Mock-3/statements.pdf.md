小 R 的展览会
【问题描述】
精灵王国科技部研发出了一项新科技——传送门，现在他们要在各大城市
举行展览会！
精灵王国的 n 个城市呈线性排列（城市从 1 到 n 编号），即第 i 个城市到
第 i+1 个城市有一条互相通达的长度为 1 的道路(i < n)，现在科技部希望将一对
（两个）传送门放到一个或两个城市中，供国民观赏。
科技部提供了免费试用服务，即来参观的人可以选择进入传送门，瞬间到
达另一个传送门所在的城市中去，当然，也可以选择不进入传送门。
现有 m 个人要参加这次展览会，每个人有一个游览计划，可以表示成二元
组(a, b)，表示他从城市 a 出发，去参观一次传送门（即要到达一个传送门，但
可以选择不进入），然后到城市 b 去。
小 R 是科技部此次展览会的负责人，她需要决定把传送门放在哪两个城
市，使得所有人走的路的总长度（即忽略参观的时间）最短，你能帮帮她吗？
注意：每个人的游览互不影响。
【输入】
第一行为两个正整数 n、m。
接下来 m 行每行两个正整数 a、b，表示一个人的游览计划。
【输出】
输出最短的总长度。
【输入输出样例】
exhibition.in exhibition.out
5 2
1 3
4 2
2
【样例解释】
将两个传送门分别放在 2、3 号城市，这样两个人都需要走 1 的长度。
【数据范围】
对于 30%的数据满足：1 ≤ n、m ≤ 100。
对于 60%的数据满足：1 ≤ n 、m ≤ 2501。
另有 20%的数据满足：所有 a = b。
对于 100%的数据满足：1 ≤ n、m ≤ 152501，1 ≤ a、b ≤ n。
```

小 C 的宝藏
【问题描述】
小 C 正在玩一款寻宝游戏，这个游戏的目的是在有限的时间内寻到尽量多
的宝藏。游戏的地图是一个 n 行 m 列的网格，每个网格可能是“.”、“#”、
“*”、“S”四种字符的一种，分别表示空地、障碍、宝藏点和玩家位置。其
中宝藏点一共有恰好 k 个，而玩家位置恰好有一个。
小 C 控制的角色每秒可以向上下左右移动一格，不能走出边界或走到障碍
上。当小 C 走到了一个宝藏点时，她可以瞬间收集这里的宝藏（这个宝藏点将
变成空地）。
小 C 一共有 T + 0.5 秒时间行动，当时间截至游戏就会结束。小 C 想在游戏
结束之前收集尽量多的宝藏（即到达的不同的宝藏点尽量多），你能帮帮她
吗？
【输入】
第一行为四个正整数 n、m、k、T。
接下来 n 行每行 m 个字符，表示第 i 行的游戏地图。
【输出】
输出时间截至之前最多收集的宝藏数。
【输入输出样例】
treasure.in treasure.out
4 5 6 9
**...
*##*.
#**..
..S..
5
【样例解释】
移动序列为“左上右右上上左左左”，共收集了 5 处宝藏。
【数据范围】
对于 20%的数据满足：2 ≤ n、m、q ≤ 10，k = 1。
对于 40%的数据满足：2 ≤ n、m、q ≤ 10，1 ≤ k ≤ 3，1 ≤ T ≤ 10。
另有 60%的数据满足：2 ≤ n、m、q ≤ 20，1 ≤ k ≤ 8。
另有 20%的数据满足：地图无障碍“#”。
对于 100%的数据满足：2 ≤ n、m、q ≤ 501，1 ≤ k ≤ 15，1 ≤ T ≤ 106。
```
