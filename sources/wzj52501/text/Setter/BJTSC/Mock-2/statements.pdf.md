```text
拓扑排序 
 
【问题描述】 
月考结束了，八班的n名同学只知道自己的分数，但他们想通过与别人的交流得
到全班的排名。为了不暴露自己具体的分数，他们每次只会与一个同学交流，并得
到谁高或者一样高的信息。这样的交流进行了m轮，得到了m个“a<b”或“a=b”的
结果（即a比b低，或a和b一样高）。且对于每个同学x，x最多与一个小于或等于其分
数的同学交流。 
你需要根据他们得到的信息，计算有多少种可能的全排名。这里允许并列，即
1<2=3=5<4与1<5=3=2<4算成一种。当然有些同学交流时可能会出现错误，导致不可
能存在任何一种满足条件的排名，此时输出0。 
 
【输入】 
第一行2个正整数n、m。 
接下来m行每行为“a < b”或“a = b”两种可能之一，a、b为不同的正整数。 
 
【输出】 
输出答案对998244353取模的结果。 
 
 
【输入输出样例】 
 
sort.in sort.out 
5 4  
1 < 2  
1 < 3  
2 < 4  
1 = 5 
5 
 
【输入输出样例解释】 
不同的的排名结果有： 
1 = 5 < 2 < 3 < 4  
1 = 5 < 2 < 4 < 3  
1 = 5 < 2 < 3 = 4  
1 = 5 < 3 < 2 < 4  
1 = 5 < 2 = 3 < 4  
 
【数据范围】 
对于20%的数据，1≤n≤8。 
对于40%的数据，1≤n≤15。 
对于60%的数据，1≤n≤100。 
另有20%的数据，m=0。 
对于100%的数据，1≤m≤n≤501，1≤a≠b≤n。 
```
