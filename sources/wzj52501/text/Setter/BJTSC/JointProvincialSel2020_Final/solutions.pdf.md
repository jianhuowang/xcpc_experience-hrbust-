```text

tree
使用 Trie 树维护这 n 个集合，但这里的 Trie 树是从二进制的最低
位到最高位开始建立的。
对于合并与插入操作，均按照 Trie 树的经典操作进行。由于将 n
棵仅包含一个元素的 Trie 树按任意顺序合并为一棵 Trie 树的总代
价不会超过将 n 个元素依次插入一棵 Trie 的代价，所以时间复杂
度为均摊 O(log n)。
对于全体 +1 操作，我们只需从根开始交换左右子树，然后递归
左子树继续操作即可。
对于查询异或，我们可以记录当前的全体异或值，当全体 +1 时
再计算答案的变化。由于 x ⊕ x + 1 = 2 lowzero(x) − 1，lowzero(x)
为 x 二进制最低位的 0。我们只用从根不断向右子树递归，查看
左子树的奇偶性即可计算 lowbit。
时空复杂度均为 O(n log n)。
```
